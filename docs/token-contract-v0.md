# Token contract v0

Status: draft, version 0. Source of truth for the roles components may read.
Decision records: `docs/decisions/0002-token-format-and-role-taxonomy.md`. The review that
produced the current file is `docs/token-review.md`.

The roles are the file's own taxonomy. shadcn/ui is a pattern reference for component
composition only: its role names are not used and there are no aliases for them.

## Layers

| Layer | Set(s) in `packages/tokens/generated/tokens.json` | Who may read it |
| --- | --- | --- |
| Primitives | `Primitives/Default` (palettes, spacing, radius, border width, font size, line height, font family and weight) | Nobody outside the token package |
| Brand scales | `Brand/Default` (`scale.{neutral,primary,secondary,destructive,success,warning,info}.50..1200`) | Nobody outside the token package. This is the swap point for a second theme |
| Semantic roles | `Semantic/Light`, `Semantic/Dark` (same names in both) | Components, through CSS variables and Tailwind utilities |
| Typography | `Typography/Desktop`, `Typography/Mobile` (same names in both) | Components, through CSS variables |

Components read only semantic roles (and component tokens, when they exist). They never
read primitives, brand scales or raw values. Light and dark are separate sets with
identical role names, so a theme is complete only if both define every role.

## Naming rules

- Lowercase kebab-case segments (`container-subtle`, `read-only`), joined by dots to form
  the token path. Letters, digits and hyphens only. No spaces, brackets, underscores or capitals.
- A name is unique across the sets that are used together. Light and dark (and desktop and
  mobile typography) are alternatives and repeat the same names on purpose.
- Every token has a `$type`.
- Every value is an alias (`{scale.neutral.300}`) except the literals listed below.

## CSS variables

The variable name is the organization prefix plus the role path with dots replaced by
hyphens.

| Role path | CSS variable |
| --- | --- |
| `surface.page` | `--cr-surface-page` |
| `actions.primary.default` | `--cr-actions-primary-default` |
| `state.focus.ring` | `--cr-state-focus-ring` |

The prefix lives in one constant (`CSS_PREFIX` in `packages/tokens/src/constants.ts`).
`TODO(decision: css-prefix)`: `--cr-` is proposed and stays provisional until the decision
record is accepted.

Themes switch by attribute and are element scoped: `:root` and `[data-theme="light"]` carry
the light values, `[data-theme="dark"]` the dark ones. A nested element with its own
`data-theme` redefines the variables for its subtree.

Besides the roles, the stylesheet carries the radius, spacing, border-width and font-family
scales and the typography styles (desktop by default, mobile under a media query,
`TODO(decision: typography-breakpoint)`).

## Tailwind utilities

`@usecredo/tailwind-config` maps each role to a Tailwind colour named after the role path
with dots as hyphens, using `@theme inline`. The role is exposed directly in every colour
utility:

| Utility | Reads |
| --- | --- |
| `bg-surface-page` | `surface.page` |
| `text-content-primary` | `content.primary` |
| `border-border-default` | `border.default` |
| `bg-actions-primary-default` | `actions.primary.default` |
| `text-actions-primary-foreground` | `actions.primary.foreground` |
| `ring-state-focus-ring` | `state.focus.ring` |

The doubled word in `border-border-default` is the utility (`border-`) followed by the role
(`border.default`). The radius scale is available as `rounded-xs` to `rounded-full`.

## Literal exceptions

Raw hex values are allowed only in two places. Everything else is an alias.

- `alpha.*`: translucent colours whose RGB must equal the scale step below, per mode. The
  validator fails if a literal's RGB differs from its source step.
- `shadow.color.*`: shadow colours.

| `alpha.<group>.*` | Light source | Dark source |
| --- | --- | --- |
| `neutral` | `scale.neutral.900` | `color.black` |
| `primary` | `scale.primary.700` | `scale.primary.500` |
| `destructive` | `scale.destructive.600` | `scale.destructive.500` |
| `white` | `color.white` | `color.white` |
| `black` | `color.black` | `color.black` |

The source table is the `ALPHA_SOURCES` constant in `packages/tokens/src/constants.ts`.
