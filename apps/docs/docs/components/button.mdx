`Button` triggers an action. It renders a native `button`, or the single child you pass when
you set `asChild` (Radix Slot), so the same styling can sit on a link.

```tsx
import { Button } from "@usecredo/ui/button";
```

## Examples

The examples below are the real `@usecredo/ui/button` component, styled by the real token and
Tailwind stylesheets. The toggle sets `data-theme` on the example frame only.

### Variants

<div className="credo-example-frame">
  <div className="credo-example" data-theme="light">
    <div className="credo-row">
      <Button>Default</Button>
      <Button variant="secondary">Secondary</Button>
      <Button variant="destructive">Destructive</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="ghost">Ghost</Button>
      <Button variant="link">Link</Button>
    </div>
  </div>
</div>

### Sizes

<div className="credo-example-frame">

### Disabled and loading

A loading button shows a spinner, sets `aria-busy` and ignores activation, but stays focusable.

<div className="credo-example-frame">
  <div className="credo-example" data-theme="light">
    <div className="credo-row">
      <Button disabled>Disabled</Button>
      <Button loading>Loading</Button>
    </div>
  </div>
</div>

  </div>
</div>

## API

Generated from the TypeScript declarations of `@usecredo/ui/button` at build time. `Button`
also accepts every native `button` attribute and forwards its `ref` to the element.
