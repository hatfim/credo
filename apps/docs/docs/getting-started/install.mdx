title: Install
---

Install the packages from the public `@usecredo` scope.

```bash
pnpm add @usecredo/ui @usecredo/tokens
pnpm add -D @usecredo/tailwind-config tailwindcss
```

Peer requirements: React 18 or 19, and Tailwind CSS v4.
