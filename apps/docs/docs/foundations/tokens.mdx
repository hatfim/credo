Every table on this page is generated at build time from `@usecredo/tokens/table.json`, the
output of the token build. Nothing is typed by hand, so the values here are the values the
stylesheet ships. Components read semantic roles and scale tokens only.

Colour roles have a light and a dark value. The second reference theme has no tokens yet.
