# Credo component catalog

This catalog holds state catalogs, interaction tests and accessibility checks for the
components in `@usecredo/ui`. Onboarding, foundations, theming and guidelines live in the
documentation site, not here.

Use the Theme control in the toolbar to switch the `data-theme` attribute on the story wrapper.
Component stories are written next to each component in `packages/ui/src/<component>/`.
